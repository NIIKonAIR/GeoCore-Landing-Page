# GeoCore™ Landing Page 🌐

Официальный лендинг B2B десктопного приложения **GeoCore™** для автоматизации камерального анализа ЗОУИТ и КПТ.

🔗 **Живой сайт:** [geocore-app.ru](https://geocore-app.ru)

---

## 📌 О проекте

Веб-ресурс предназначен для презентации B2B-решения кадастровым инженерам, демонстрации архитектуры работы приложения (Workflow) и распространения дистрибутива программы (7-дневный триал).

### Ключевой функционал сайта:
* **Главная страница (`index.html`):** Описание проблематики отрасли, сравнение ручной обработки с автоматизированной (сокращение времени с 240 до 3 минут).
* **Workflow (`workflow.html`):** Пошаговая демонстрация гео-ядра (работа с `.gpkg`, `R-tree`, `Shapely`, `GeoPandas` и многопоточностью `QThread`).
* **Скачивание (`download.html`):** Выдача `.exe` инсталлятора, снятие возражений по Windows SmartScreen / HWID и прямая связь с разработчиком.

---

## 🛠 Технологический стек

* **Frontend:** HTML5, Tailwind CSS (CDN), Inter Font.
* **Hosting & Infrastructure:** GitHub Pages, Custom Domain DNS (`geocore-app.ru`), SSL/TLS Enforce.
* **Design & UX:** Адаптивная темно-стилизованная тема (Slate/Rose palette), микро-анимации.
