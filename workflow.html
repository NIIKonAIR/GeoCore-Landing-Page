Архитектура и Workflow программы GeoCore™

GeoCore™ объединяет автономный предварительный расчет кварталов и точный пакетный анализ выписок без сложной настройки сторонних ГИС.

Шаг 1 из 4

Граница ЗОУИТ — из любого рабочего источника

Выберите удобный способ ввода: программа быстро приведёт геометрию к рабочему виду.

  • Кадастровый номер: Автоматический онлайн-запрос геометрии зоны.
  • DXF: Автоматическая очистка мусора, текстов и размеров; 2D-сплющивание.
  • XML: Импорт XML-файлов границ без ручной конвертации.
INPUT MODULE
[Number Query] ➔ [DXF/XML Parser] ➔ [2D Flattening]
AUTONOMOUS SPATIAL FILTER
.gpkg + R-tree ➔ Список целевых кварталов для КПТ
Шаг 2 из 4

Автономный подбор кварталов и экономия бюджета

Встроенная локальная база .gpkg со вшитым пространственным индексом R-tree мгновенно определяет, какие именно кадастровые кварталы пересекает зона.

  • Автономная база: Работает полностью офлайн прямо на вашем компьютере.
  • Точный список для КПТ: Программа формирует список затронутых кварталов, чтобы вы скачали только нужные файлы и не тратили деньги на покупку лишних выписок вслепую.
  • Прозрачный процесс: Вы скачиваете XML-файлы КПТ по полученному списку из официальных источников и передаете их в программу.
Шаг 3 из 4

Гео-ядро считает пересечения без ручной рутины

Расчёты выполняются последовательно и не блокируют работу инженера.

  • Shapely + GeoPandas: Математические расчёты геометрии на проверенном стеке.
  • Метрики: Площадь наложения в кв. м и процент пересечения для каждого участка.
  • QThread: Многопоточная обработка: приложение не зависает даже на сотнях XML КПТ.
GEOMETRY ENGINE
MultiThread QThread ➔ Intersection Polygon Area Metrics
OUTPUT EXPORT
01 / Excel Ведомость
02 / DXF Многослойный CAD-чертеж
Шаг 4 из 4

На выходе — ведомость и CAD-чертеж

Два формата результата закрывают аналитическую и графическую часть проекта.

  • Excel: Полная ведомость кадастровых номеров и площадей наложений.
  • DXF Чертеж: Многослойный файл с разнесением цветов ACI для ЗОУИТ, участков и подписей.
